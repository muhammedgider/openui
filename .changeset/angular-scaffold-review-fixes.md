Add Angular bindings for OpenUI Lang with component libraries, streaming rendering, form state, tool queries and mutations, and render-error recovery.

Include Angular in the fixed Lang release group so it versions and publishes alongside lang-core, react-lang, svelte-lang, and vue-lang.

Keep context-based field reads reactive without remounting components, and expose streaming/query-loading injection helpers as Angular signals.
